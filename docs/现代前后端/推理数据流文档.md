
# EasyYolo 推理数据流（现代前端）

> 前端：Vue 3 + TypeScript + Pinia + Element Plus | 后端：FastAPI + Ultralytics YOLO

## 1. 数据流总览

| 阶段 | 前端操作 | 前端文件与函数 | 前后端通信 | 后端文件与函数 | 数据处理与存储 |
|:-----|:---------|:-------------|:-----------|:--------------|:--------------|
| 1. 模型选择 | 侧边栏点击模型项 | ModelSidebar.vue → modelStore.switchModel() | POST /switch_model (FormData) | api.py: switch_model() | 更新全局 current_model_name |
| 2. 图片/视频上传 | 拖拽或点击上传区域 | InferenceView.vue: handleFileChange() | - | - | 保存到 selectedFiles (ref) |
| 3. 单张图片推理 | 点击「开始推理」 | InferenceView.vue: runSinglePredict() | POST /predict (FormData) | inference_service.py: handle_single_predict() | 保存图片→执行推理→入库 |
| 4. 批量图片推理 | 选择多张图片后点击推理 | InferenceView.vue: runBatchPredict() | POST /predict_batch (FormData) | inference_service.py: batch_predict_generator() | 逐张推理并推送进度(SSE) |
| 5. 视频推理 | 选择视频后点击推理 | InferenceView.vue: runVideoPredict() | POST /predict_video (FormData) | inference_service.py: video_predict_generator() | 逐帧推理并推送进度(SSE) |
| 6. 结果展示 | 推理完成后显示结果 | InferenceView.vue: 响应式绑定 resultImgSrc | - | - | 条件渲染结果图片/视频 |
| 7. 历史管理 | 侧边栏历史记录操作 | InferenceView.vue: fetchHistory() / deleteHistoryItem() | GET/DELETE /history | db_service.py | 从 SQLite 查询/删除 |

## 2. 详细数据流分析

### 阶段1: 模型选择

| 步骤 | 前端操作 | 前端文件与函数 | 前后端通信 | 后端文件与函数 | 数据处理与存储 |

| 1.1 | 侧边栏渲染模型列表 | ModelSidebar.vue: sections (computed) | - | - | 从 modelStore.models 读取 |
| 1.2 | 用户点击模型名 | ModelSidebar.vue: handleModelClick() | - | - | 推理模式下调用 store |
| 1.3 | Pinia store 发起切换 | stores/models.ts: switchModel() | POST /switch_model (FormData) | api.py: switch_model() | 更新 current_model_name |
| 1.4 | 后端加载模型 | - | - | yolo_service.py: load_model() | 加载 .pt 文件到内存 |
| 1.5 | Store 刷新模型列表 | stores/models.ts: fetchModels() | GET /models | api.py: get_models() | 重新扫描模型目录 |
| 1.6 | UI 响应式高亮当前模型 | ModelSidebar.vue: :class active | - | - | name === modelStore.currentModelName |

### 阶段2: 图片/视频上传

### 阶段3: 单张图片推理

| 步骤 | 前端操作 | 前端文件与函数 | 前后端通信 | 后端文件与函数 | 数据处理与存储 |
|:-----|:---------|:-------------|:-----------|:--------------|:--------------|

## 3. 关键数据结构

### 推理结果（API 返回）
```typescript
{
  result_url: string    // 结果图片/视频 URL
  original_url: string  // 原始文件 URL
  time: string          // 推理时间
}
```

### 推理历史记录（InferenceHistory）
```sql
-- SQLite
id          INTEGER PRIMARY KEY AUTOINCREMENT
model_name  TEXT NOT NULL
original_url TEXT
result_url  TEXT
created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
```

### SSE 事件格式
```
data: {"current": 3, "total": 99, "original_url": "...", "result_url": "..."}
```

## 4. 前端状态管理（Pinia）

| Store | 文件 | 关键状态 |
|:------|:-----|:---------|
| models | stores/models.ts | models (raw/yolo/trained 列表), currentModelName, loading |
| app | stores/app.ts | activePage, sidebarCollapsed, detailsModelName |

推理页面本地状态（InferenceView.vue refs）：
| 状态 | 类型 | 说明 |
|:-----|:-----|:-----|
| selectedFiles | File[] | 用户选择的文件 |
| isVideo | boolean | 是否为视频模式 |
| originalImgSrc | string | 原始图片预览 Object URL |
| resultImgSrc | string | 推理结果图片 URL |
| predicting | boolean | 推理进行中标志 |
| batchProgress | {current, total} | 批量推理进度 |
| historyItems | HistoryItem[] | 当前模型的历史记录 |

## 5. 关键 API 端点

| 端点 | 方法 | 功能 | 参数 | 返回值 |
|:-----|:-----|:-----|:-----|:-------|
| /switch_model | POST | 切换当前模型 | model_name, category (FormData) | {status, current_model} |
| /predict | POST | 单张图片推理 | file (FormData) | {result_url, original_url, time} |
| /predict_batch | POST | 批量图片推理 | files[] (FormData) | SSE 流 |
| /predict_video | POST | 视频推理 | file (FormData) | SSE 流 |
| /history | GET | 获取推理历史 | model_name (query) | [{id, model_name, original_url, ...}] |
| /history/{id} | DELETE | 删除单条记录 | id (path) | {status} |
| /history | DELETE | 清空历史 | model_name (query) | {status} |

## 6. 新旧前端对比

| 维度 | 基础前端 (JS) | 现代前端 (Vue) |
|:-----|:--------------|:----------------|
| 架构 | 原生 ES6 模块 (api/dom/events/ui/state) | Vue 3 SFC + Pinia Store |
| 状态管理 | 全局 state 对象 + localStorage | Pinia 响应式 Store + watch 持久化 |
| HTTP 请求 | 自定义 api.js (fetch) | Axios 实例（统一拦截）+ 原生 fetch（SSE） |
| UI 组件 | 原生 DOM 操作 + innerHTML | Element Plus + 响应式模板 |
| 路由 | 单页无路由（面板切换） | Vue Router（/inference /training /details） |
| 类型检查 | 无 | TypeScript 严格模式 |
| CSS | CSS 自定义属性 + 独立 CSS 文件 | Scoped CSS + 全局 CSS 变量 |
