
# EasyYolo 训练数据流（现代前端）

> 前端：Vue 3 + TypeScript + Pinia + Element Plus | 后端：FastAPI + Ultralytics YOLO

## 1. 数据流总览

| 阶段 | 前端操作 | 前端文件与函数 | 前后端通信 | 后端文件与函数 | 数据处理与存储 |
|:-----|:---------|:-------------|:-----------|:--------------|:--------------|
| 1. 数据集上传 | 选择 zip 并上传 | TrainingView.vue: handleDatasetUpload() | POST /upload_dataset (FormData) | training_service.py: extract_and_validate_dataset() | 保存 zip → 解压 → 验证 data.yaml |
| 2. 训练参数配置 | 填写参数并点击「开始训练」 | TrainingView.vue: startSingleTraining() | POST /start_training (FormData) | training_service.py: start_training_task() | 后台线程启动 YOLO 训练 |
| 3. 训练执行 | 后台线程执行 | - | - | training_service.py: _run_yolo_training() | 加载模型→训练→保存产物 |
| 4. 进度轮询 | 定时查询训练进度 | stores/training.ts: startPoller() | GET /training_progress | training_service.py: get_progress() | 返回 training_state 字典 |
| 5. 训练停止 | 点击「停止训练」 | TrainingView.vue: stopCurrentTraining() | POST /stop_training | training_service.py: stop_training() | 设置 threading.Event |
| 6. 结果展示 | 自动跳转详情页 | 轮询器检测完成 → router.push() | GET /training_history/{name} | db_service.py: get_training_record() | 查询 TrainingHistory |
| 7. 多任务队列 | 添加/删除任务，顺序执行 | TrainingView.vue + stores/training.ts | POST /start_training（逐个） | training_service.py（复用单任务接口） | localStorage 持久化队列 |

## 3. 关键数据结构

### 训练状态（training_state）
```python
training_state = {
    "model_name": None,        # 正在训练的模型名
    "status": "idle",          # idle / training / success / error / stopped / early_stopped
    "progress": 0,             # 当前 epoch
    "total": 0,                # 总 epochs
    "metrics": {},             # 实时指标 (box_loss, mAP50 等)
    "eta": "计算中...",         # 预计剩余时间
    "error_msg": "",           # 错误信息
    "start_time": 0,           # 开始时间戳
    "last_epoch_time": 0,      # 上一轮结束时间
    "is_early_stopped": False, # 是否早停
    "early_stopped_epoch": 0   # 早停轮次
}
```

### 训练任务（TrainingTask）
```typescript
interface TrainingTask {
  id: number
  index: number                  // 任务序号 (1-9)
  title: string                  // "任务一" ~ "任务九"
  modelSource: 'existing' | 'previous'  // 基础模型来源
  baseModel: string              // 基础模型名
  newModelName: string           // 产出模型名
  description: string            // 任务描述
  datasetPath: string            // 数据集路径
  datasetName: string            // 数据集显示名
  parameters: TrainingParams     // 训练超参数
  status: 'pending' | 'running' | 'completed' | 'failed'
  progress: number
  totalEpochs: number
  errorMessage: string
}
```

### 训练参数（TrainingParams）
```typescript
{
  epochs: 60, patience: 15, batch: 12, imgsz: 640,
  optimizer: 'auto', lr0: 0.01, lrf: 0.01,
  momentum: 0.937, weight_decay: 0.0005,
  warmup_epochs: 3.0, warmup_momentum: 0.8, cos_lr: false,
  // ... 共 27 个超参数
}
```

## 6. 队列训练特性

- **任务上限**: 9 个（MAX_TRAINING_TASKS）
- **模型依赖链**: 任务 N 可使用任务 N-1 产出的模型作为基础模型
- **断点恢复**: 队列状态持久化到 localStorage，刷新页面后自动恢复
- **轮询间隔**: 全局 4s (TRAINING_POLL_INTERVAL)，队列内部 2s (QUEUE_POLL_INTERVAL)
- **早停兼容**: 早停完成的模型仍可作为后续任务的基础模型

## 7. 新旧前端对比

| 维度 | 基础前端 (JS) | 现代前端 (Vue) |
|:-----|:--------------|:----------------|
| 单任务状态 | 全局 state 对象 | trainingStore (Pinia) |
| 多任务队列 | multiTaskManager 对象 | trainingStore.tasks[] + localStorage |
| 进度更新 | DOM 操作 updateTrainingDashboard() | 响应式 computed + template 绑定 |
| 参数编辑 | 内联表单 | el-dialog + localParams (ref) 副本 |
| 模式切换 | switchTrainingMode() DOM 切换 | v-if="trainingMode === 'multi'" |
| 类型安全 | 无 | TrainingParams / TrainingTask 接口约束 |
