
# EasyYolo 管理数据流（现代前端）

> 前端：Vue 3 + TypeScript + Pinia + Element Plus | 后端：FastAPI + SQLite

## 1. 数据流总览

| 阶段 | 前端操作 | 前端文件与函数 | 前后端通信 | 后端文件与函数 | 数据处理与存储 |
|:-----|:---------|:-------------|:-----------|:--------------|:--------------|
| 1. 模型列表获取 | 应用启动时自动获取 | App.vue → modelStore.fetchModels() | GET /models | api.py: get_models() | 扫描 models/raw, models/yolo, models/trained |
| 2. 模型上传 | 详情页点击「导入模型」 | DetailsView.vue: handleUploadModel() | POST /upload_model (FormData) | api.py: upload_model() | 保存 .pt 文件到 models/yolo/ |
| 3. 模型切换 | 侧边栏点击模型名 | ModelSidebar.vue → modelStore.switchModel() | POST /switch_model (FormData) | api.py: switch_model() | 更新 current_model_name |
| 4. 模型重命名 | 右键菜单 → 重命名 | ModelSidebar.vue → DetailsView.vue handleRenameModel() | POST /rename_model (JSON) | api.py: rename_model() | 文件重命名 + 数据库引用更新 |
| 5. 模型删除 | 右键菜单 → 删除 | ModelSidebar.vue → DetailsView.vue handleDeleteModel() | DELETE /delete_model | api.py: delete_model() | 删除文件 + 关联记录 |
| 6. 模型介绍编辑 | 右键菜单 → 修改介绍 | ModelSidebar.vue → DetailsView.vue | POST /update_model_description (JSON) | api.py: update_model_description() | 更新 TrainingHistory.description |
| 7. 模型详情查看 | 点击详情页模型名或导航到 /details | DetailsView.vue + ModelSidebar.vue | GET /training_history/{name} | db_service.py: get_training_record() | 查询训练记录 + 图表 |

## 3. 关键数据结构

### 模型列表（API 返回）
```typescript
{
  models: {
    raw: ["yolo11n.pt", "yolo11s.pt", "yolo11m.pt"],
    yolo: ["custom_model.pt"],
    trained: ["steel_v1.pt", "steel_v2.pt"]
  },
  current_model: "yolo11n.pt"
}
```

### 模型详情（ModelDetail）
```typescript
interface ModelDetail {
  model_name: string
  base_model: string            // 基础模型名
  dataset: string               // 训练数据集名
  parameters: string            // 训练参数 JSON 字符串
  description: string           // 模型介绍
  time: string                  // 训练完成时间
  best_metrics?: string         // 最佳一轮指标 JSON
  best_epoch?: number           // 最佳轮次
  early_stopped?: number        // 0:正常完成 1:早停
  early_stop_epoch?: number     // 早停轮次
  eval_table?: string           // 每类评估指标 JSON
}
```

### 模型分类
```typescript
type ModelCategory = 'raw' | 'yolo' | 'trained'
// raw:    官方预训练模型，不可重命名/删除
// yolo:   用户导入的模型，可重命名/删除
// trained: 训练产出的模型，可重命名/删除，有详情页
```

## 4. 前端状态管理（Pinia）

### models Store (stores/models.ts)
```typescript
{
  models: { raw: string[], yolo: string[], trained: string[] }
  currentModelName: string      // 当前推理模型
  currentCategory: ModelCategory
  loading: boolean
  // Actions: fetchModels, switchModel, uploadModel, renameModel, deleteModel, updateDescription
}
```

### app Store (stores/app.ts)
```typescript
{
  activePage: string            // 'inference' | 'training' | 'details'
  sidebarCollapsed: boolean     // 侧边栏展开/折叠
  detailsModelName: string      // 详情页当前查看的模型名
}
```

## 5. 关键 API 端点

| 端点 | 方法 | 功能 | 参数 |
|:-----|:-----|:-----|:-----|
| /models | GET | 获取所有可用模型 | 无 |
| /upload_model | POST | 上传自定义模型 | file, custom_name (FormData) |
| /switch_model | POST | 切换当前模型 | model_name, category (FormData) |
| /rename_model | POST | 重命名模型 | {old_name, new_name, category} (JSON) |
| /delete_model | DELETE | 删除模型 | model_name, category (query) |
| /update_model_description | POST | 更新模型介绍 | {model_name, description} (JSON) |
| /training_history/{name} | GET | 获取训练记录详情 | name (path) |

## 6. 数据存储位置

| 数据类型 | 存储位置 | 说明 |
|:---------|:---------|:-----|
| 官方预训练模型 | models/raw/ | 不允许重命名和删除 |
| 用户导入模型 | models/yolo/ | 用户上传的自定义 .pt 文件 |
| 训练产出模型 | models/trained/ | 训练后的 best.pt |
| 训练图表 | backend/trainchart/{model_name}/ | 各类评估曲线图 |
| 推理记录 | database/yolo_app.db (InferenceHistory 表) | 历史推理记录 |
| 训练记录 | database/yolo_app.db (TrainingHistory 表) | 训练参数与指标 |

## 7. 新旧前端对比

| 维度 | 基础前端 (JS) | 现代前端 (Vue) |
|:-----|:--------------|:----------------|
| 模型列表渲染 | ui.renderModelList() DOM 操作 | ModelSidebar.vue: v-for 响应式列表 |
| 对话框管理 | 全局 showXxxModal() + hidden class | el-dialog + v-model 布尔值 |
| 右键菜单 | 自建定位 + 全局事件 | Teleport to body + capture 事件 |
| 状态刷新 | refreshApp() → DOM 全量重绘 | modelStore.fetchModels() → 响应式更新 |
| 详情页路由 | 无路由，面板切换 | Vue Router /details/:modelName? |
| 表单处理 | 原生 DOM .value 取值 | v-model 双向绑定 |
